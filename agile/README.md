# Agile Scrum Deliverables — Team Pulse
**Project:** Development of AI Based Startup Idea Validator with Market Analysis Assistance  
**Program:** Infosys Springboard 7.0 (Batch 3)  
**Team:** Team Pulse  

This directory contains the official Agile Scrum deliverables required for Deliverable 1 and Deliverable 2 of the Infosys Springboard internship.

---

## 📁 Agile Files in this Folder

1. **[Agile_Sprint_Backlog_Sheet.csv](./Agile_Sprint_Backlog_Sheet.csv)**
   - Structured tabular backlog containing all 18 User Stories across Sprints 1–4.
   - Includes User Personas, Requirements, Acceptance Criteria, Story Points (104 total), MoSCoW Prioritization, Verification Deliverables, and Done status.
   - *Tip:* Can be imported directly into **Google Sheets** (`File` -> `Import` -> `Upload`) to share as your Google Drive Agile Sheet submission link!

2. **[AGILE_SCRUM_MASTER_SHEET.md](./AGILE_SCRUM_MASTER_SHEET.md)**
   - Executive Markdown view of the Sprint Velocity, User Story matrix, Scrum Team allocations, and burndown metrics.

3. **[agile-development-document.md](./agile-development-document.md)**
   - Comprehensive Agile specification document with Scrum Gantt charts, Mindmaps, Definition of Ready (DoR), Definition of Done (DoD), and Retrospectives.
